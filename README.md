# 📊 NovaRetail+ — Análisis de Datos

## 📌 Descripción

Proyecto de análisis exploratorio de datos realizado para **NovaRetail+**, una plataforma de comercio electrónico.

El objetivo es analizar el comportamiento de los clientes e identificar relaciones entre variables como compras, visitas, satisfacción, membresía premium, abandono e ingreso anual.

## 🎯 Objetivo

Identificar los factores que presentan una mayor relación con el **ingreso anual generado por los clientes**, utilizando técnicas de análisis estadístico y visualización de datos.

## 🛠️ Tecnologías

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔎 Análisis realizado

- Limpieza y preparación de datos.
- Análisis exploratorio.
- Estadística descriptiva.
- Análisis de variables categóricas y binarias.
- Matriz de correlación.
- Visualización mediante gráficos.
- Interpretación de resultados.
